# Objetivo

Migrar o data warehouse on-premises para a nuvem, reduzindo custo de
infraestrutura e habilitando análises em tempo quase real.

# Escopo

* Inventário das tabelas e pipelines existentes.
* Reescrita dos pipelines de ingestão.
* Validação de paridade de dados.

# Dependências

* Segue o [processo de resposta a incidentes](/processos/resposta-incidente.md) durante a janela de corte.
* Métricas de sucesso definidas no [glossário de métricas](/referencias/glossario-metricas.md).
