# Métricas

| Métrica | Definição |
|---------|-----------|
| Taxa de autoatendimento | % de interações resolvidas sem atendente humano. |
| Taxa de ativação | % de clientes que concluem o onboarding em 7 dias. |
| Usuários ativos semanais | Usuários únicos com ao menos uma ação em 7 dias. |

# Uso

Estas definições são referenciadas pelo [Projeto Aurora](/projetos/aurora.md)
e pelo [processo de onboarding](/processos/onboarding-cliente.md).
